# Mapa održavanja

Zidni operativni pregled lokacija, uređaja i režima podrške koje održavate — sve što je u radu.

## Šta prikazuje

- **24/7:** Kopaonik, Zlatibor, Stara planina (kapije / kiosci / prodaja / LCM posebno), Aerodrom, SrbijaVoz
- **8–16h / sezona:** Webshop, Kotor, Petnica, SECAM, parking, Ada, Goč…
- **Call centar:** Estuar korisnici, Lasta A.D., distributeri Teron & Estuar

## Pokretanje

```bash
npm install
npm run dev -- --port 3847
```

Otvorite [http://localhost:3847](http://localhost:3847).

## Podaci

Inventar lokacija je u `src/data/inventory.ts`. Tu menjate brojeve uređaja, napomene o podršci i pozicije na mapi.
